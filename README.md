# yoshijyk-lehman-presentation

A simple, interactive HTML presentation.

## How to Use

1. Open `index.html` in your web browser
2. Navigate through slides using:
   - Arrow keys (← →)
   - Navigation buttons at the bottom
   - Spacebar to go to next slide
   - Home/End keys to jump to first/last slide
3. Press 'F' to toggle fullscreen mode

## Features

- Clean, modern design with gradient background
- Smooth transitions between slides
- Keyboard navigation support
- Responsive layout
- Fullscreen mode

## Customization

- Edit `index.html` to modify slide content
- Modify `styles.css` to change colors and styling
- Update `script.js` for different navigation behavior
